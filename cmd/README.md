# 后端命令入口

`cmd/` 只存放可执行程序入口，不承载业务实现。公共业务逻辑位于
`internal/`，命令入口负责解析参数、组装依赖并调用对应服务。

## 目录与文件

| 目录 | 文件 | 作用 |
| --- | --- | --- |
| `server/` | `main.go` | 后端 API 主进程入口；加载配置，初始化 MySQL、Redis、账号、历史、Agent 和数据集服务，注册 HTTP 路由，并处理优雅停机。 |
| `seed/` | `main.go` | 演示数据初始化命令；根据 `-months` 和 `-orders` 参数重建电商业务表并生成样例订单数据。 |
| `rag-index/` | `main.go` | RAG 建索引命令；可先删除 Milvus 知识集合，再将 Markdown 文档切块，并重建指标描述向量集合。 |

## 启动关系

`server` 是生产运行所需的主入口。`seed` 和 `rag-index` 是初始化工具，
通常在首次部署或需要重建演示数据、知识索引时执行。
